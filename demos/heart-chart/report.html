The chart

How this chart was chosen

Analytical question Off-taxonomy — this is a parametric-curve visualization, not a data-analytic question. The prompt discipline in /render-chart flags this class and substitutes per SKILL §0.4.
Chart type picked Connected Scatter Plot with an ordered x encoding and a synthetic single-value hue field on color with scheme: "reds". This traces the heart curve as one continuous stroke and gives it a red hue without dropping to a Vega-Lite escape hatch.
Alternates considered
  • Pie Chart + innerRadius for a donut with a heart glyph in the center — rejected because the glyph would need a host-side overlay, not Flint's responsibility.
  • Radar Chart filled red — rejected because a radar polygon is a polygon, not a heart.
  • Scatter Plot (unconnected) with 200+ red points — rejected because the closed outline traced by Connected Scatter Plot reads more clearly as a heart.
Anti-patterns avoided Did not chart blind — computed 48 real parametric points from x(t) = 16 sin³ t, y(t) = 13 cos t − 5 cos 2t − 2 cos 3t − cos 4t. Did not force red via Vega-Lite escape hatch; used scheme: "reds" on a single-category color binding. Kept the canvas square (480×480) so the heart isn't horizontally squished.
